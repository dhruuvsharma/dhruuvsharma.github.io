Research

Transformer vs. baseline
on order-flow data
FDT-N: Footprint Distribution Transformer
Dhruv Sharma · manuscript, 2026 · arXiv submission pending endorsement

A 372K-parameter ragged-set transformer over full order-flow footprint rows, trained with three seeds and selected on validation loss only. On held-out data it beat persistence by 7.25% (q50 MAE) but lost to a train-only ridge baseline by 2.68%, with ridge winning 55 of 56 horizon-target cells. ONNX export matches PyTorch to 2.4e-7. A documented negative result.

Causal hierarchical
quantile forecasting
CHMT-Q: Causal Hierarchical Market Transformer with Quantiles
Dhruv Sharma · manuscript, 2026 · arXiv submission pending endorsement

A 2.1M-parameter transformer with separate bar, L1 and L2 order-book encoders, quality-aware fusion, and monotone q10/q50/q90 heads. I built a strict causal data contract: content-hashed shards, split-bound scalers, and walk-forward evaluation with purge and embargo. Weighted pinball loss improved 2.26% over an empirical baseline, but the directional and cost tests failed, so the model was not deployed.

1.5B narrow
code model design
HTT: Hyperion Terminal Transformer
Dhruv Sharma · architecture paper, 2026

Design of a 1.52B-parameter decoder-only model specialized for writing trading strategies and visualizers: RMSNorm, RoPE, SwiGLU, grouped-query attention, 8 global and 24 sliding-window layers, a 32K domain tokenizer, and grammar-constrained decoding. Success is defined as sealed functional correctness (compiles, passes hidden tests, respects capability limits), and every design choice is paired with an ablation and a stop condition.

drone-vs-gunner: adversarial self-play from pixels
2026 · PyTorch, Isaac Lab
code

A camera-only quadcopter evader against a turret gunner, trained in simulation with the goal of transferring both to a real drone and a 720° robotic arm. It uses independent PPO with snapshot-pool self-play, PFSP opponent sampling, ELO tracking, a 5-stage gated curriculum, and an asymmetric actor-critic (pixel actor, privileged critic). A pure-PyTorch mock environment shares the Isaac Lab interface, so the whole pipeline can be tested on a CPU. The full GPU training run is in progress.

Outfit Matcher: from-scratch ViT for photo-to-render retrieval
2026 · PyTorch, DDP
white paper and code available on request

A ViT-S/16 trained from scratch (21.9M parameters, no pretrained weights) with supervised contrastive and auxiliary cross-entropy losses, matching real garment photos to 3D-render catalogs. Domain randomization closes the render-to-photo gap. Evaluation uses a garment-level holdout with leave-one-view-out Recall@K. An earlier ResNet-18 version reached Recall@10 of 83.5% on DeepFashion In-Shop.
